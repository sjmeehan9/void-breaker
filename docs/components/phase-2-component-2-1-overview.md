# Phase 2 Component 2.1 Overview — Human Setup & Asset Preparation

## Summary

Component 2.1 creates all placeholder visual and audio assets required to unblock Phase 2 gameplay components (2.2–2.8). Sprites are low-fidelity geometric shapes generated by a Pillow script; sound stubs are real `.wav` files provided by the developer.

## Sprites Created

| File | Shape | Size | Colour |
|------|-------|------|--------|
| `ship.png` | Upward-pointing triangle | 32×32 | White |
| `asteroid_large.png` | Irregular polygon (seeded) | 68×68 | Grey |
| `asteroid_medium.png` | Irregular polygon (seeded) | 44×44 | Grey |
| `asteroid_small.png` | Irregular polygon (seeded) | 24×24 | Grey |
| `projectile_player.png` | Filled ellipse | 8×8 | Cyan |
| `currency_pickup.png` | Diamond | 16×16 | Gold |
| `explosion_particle.png` | Filled ellipse | 6×6 | Orange-white |

All sprites are RGBA PNG with transparent backgrounds. The ship sprite's forward direction points upward to match Arcade's coordinate system (`ship.angle + 90` thrust convention from solution design).

## Sounds Present

All required `.wav` files exist in `assets/sounds/`: `fire.wav`, `explode_small.wav`, `explode_medium.wav`, `explode_large.wav`, `hit.wav`, `pickup_currency.wav`, `level_clear.wav`, `game_over.wav`. An additional `player_hit.wav` is also present (bonus asset from developer).

## Supporting Scripts

- `scripts/generate_placeholder_sprites.py` — Regenerates all sprites from code using Pillow. Deterministic via seeded random for asteroid irregularity.
- `scripts/verify_assets.py` — Verifies all sprites exist with correct dimensions/mode and all sounds are valid WAV containers.

## Design Decisions

- **Pillow generation over manual editing**: Ensures reproducibility, version-controllable source, and easy regeneration if dimensions change.
- **Asteroid padding**: 4px padding around asteroid sprites for drawing margin. Functionally equivalent since Arcade reads actual image dimensions.
- **Ship orientation**: Points upward (90°) per solution design thrust formula `ship.angle + 90`.

## Notes

These are intentionally low-fidelity placeholder assets. They will be replaced in Phase 5.1 with final art and polished audio.
